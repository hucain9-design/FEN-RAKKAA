# Fen Rakkaa — Strategic Project Development Proposal

PTMT9002 · Hussain Shaany S2610358

A static site presenting Project Fen Rakkaa: an overview, the full proposal, and the defence presentation.

## Files
- `index.html` — the site (Overview · Proposal · Presentation)
- `presentation.html` — the standalone 8-slide deck (arrow keys to navigate; toolbar to print to PDF)
- `_ds/` — Modernist design-system stylesheet
- `support.js`, `deck-stage.js` — runtime for the page and the deck

## Publish with GitHub Pages
Repo must be **public** (free Pages). Settings -> Pages -> Deploy from a branch -> `main` / `/ (root)` -> Save.
